# UNFILED-IP
# Synthetic Validation Protocol

The supplied first milestone uses:

- 16 phase-diverse observations;
- 4× high-resolution truth relative to the sensor grid;
- truth PSF sigma 0.82 LR pixels;
- estimated PSF sigma 0.70 LR pixels;
- Poisson-Gaussian truth noise;
- mean normalized squared-residual gate threshold 8.0;
- a false H-shaped microglyph injected at amplitude 0.72; and
- a required challenge demotion rate of at least 0.95 in automated tests.

This is a development protocol. A release benchmark must freeze calibration, development, locked-test, mismatch, and adversarial seeds before final reporting.
